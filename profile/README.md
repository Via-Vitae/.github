# ViaVitae IT Technologies

**Ethical technology for communities, charities and social-good organisations.**

ViaVitae builds privacy-first, GDPR-compliant digital solutions for religious
communities, charities and mission-driven organisations across Europe.

## Principles

- **Privacy by design** — GDPR-compliant from the ground up, EEA data residency
- **Accessibility** — WCAG 2.2 AA across every user-facing surface
- **Transparency** — Open governance, ADRs for every architectural decision
- **Security** — Least-privilege, pinned dependencies, full secrets scanning
