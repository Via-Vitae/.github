# Support

## How to get help

| Channel | Use for |
| --- | --- |
| **GitHub Issues** | Bug reports and feature requests in the relevant repository |
| **GitHub Discussions** | Questions, ideas, and general discussion |
| `security@viavitae.com` | Security vulnerabilities — **never** use public issues |
| `dpo@viavitae.com` | Data protection, privacy, and GDPR questions |
| `legal@viavitae.com` | Licensing, legal, and compliance questions |

## Before asking

1. Search existing issues and discussions — your question may already be answered.
2. Check the repository's `README.md` and `docs/` directory.
3. Review the [contributing guidelines](CONTRIBUTING.md).

## What to include

- The repository and version/commit you are using
- Steps to reproduce the issue
- Expected vs actual behaviour
- Logs or screenshots where helpful (never include personal data or secrets)
